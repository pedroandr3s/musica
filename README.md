Stage Timer es una herramienta pensada para roadies, stage managers y bandas en vivo, que permite gestionar de forma clara y en tiempo real los tiempos de montaje, prueba de sonido y show.

El sistema cuenta con dos vistas:
	•	Panel de Administración (Stage Manager):
Desde aquí se configuran las bandas, se asignan los tiempos, y se controla el inicio, pausa o reinicio del cronómetro. También permite enviar avisos directos al visualizador.
	•	Visualizer (Pantalla de Banda):
Una vista simple y a pantalla completa, ideal para proyectar o mostrar en monitores. Presenta el nombre de la banda y el tiempo restante en grande, con cambios de color para indicar advertencias (verde, amarillo, rojo).

Con esta plataforma se logra una comunicación más clara entre producción y músicos, se reducen retrasos y se mantiene el orden en cada escenario.

Ideal para:
	•	Festivales con varias bandas
	•	Eventos en vivo con cambios rápidos de escenario.
	•	Equipos de producción que necesitan control y coordinación.
